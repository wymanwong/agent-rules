Same PC: http://localhost:<PORT>/ (default PORT from terminal when you run npm start).

Phone or another computer: use this machine’s LAN IP, e.g. http://192.168.x.x:<PORT>/. Do not use localhost there — localhost always means “this phone/PC”, not your server PC.

If this message stays forever: F12 → Console. If the page is white, you are probably not hitting this server.
